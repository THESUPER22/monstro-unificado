5. CAPTURA E QUALIDADE DO FLUXO

Não apresente uma estimativa como se fosse Times & Trades real. Diferencie claramente:

•
agressão identificada pelo feed;

•
inferência por tick/preço;

•
livro de ofertas observado;

•
volume sem direção confiável;

•
dado ausente, atrasado ou congelado.

Regras de captura

•
usar o símbolo real selecionado pelo robô, nunca fixar WDOU26 sem validar;

•
usar cursor monotônico por time_msc e, em caso de empate, uma chave adicional estável;

•
não processar o mesmo tick duas vezes;

•
tratar reinício do terminal, mudança de contrato, salto de timestamp e relógio incorreto;

•
limitar a janela de consulta para não reprocessar todo o histórico a cada iteração;

•
evitar sleep agressivo que consuma CPU;

•
não deixar exceção do coletor derrubar o robô;

•
registrar taxa de ticks, atraso, último timestamp, duplicatas e erros;

•
aplicar lock ou estrutura thread-safe ao estado compartilhado;

•
não chamar operações de trading a partir do coletor.

Flags e fallback

A IA implementadora deve confirmar na documentação/ambiente as constantes do MetaTrader 5 e não inventar flags. Se as flags de agressão não forem confiáveis ou não estiverem disponíveis:

•
marcar o método como inferido ou indisponivel;

•
não chamar o resultado de “agressão real”;

•
exibir um aviso no dashboard;

•
preservar o último estado apenas com indicador de staleness;

•
não usar o dado como gatilho de ordem.

Métricas mínimas

Implementar somente métricas que tenham definição clara e teste:

•
volume comprador;

•
volume vendedor;

•
delta: comprador menos vendedor;

•
delta acumulado da janela;

•
volume total;

•
razão compradora/vendedora, com proteção para divisão por zero;

•
número de ticks processados;

•
preço último, bid e ask quando disponíveis;

•
spread;

•
direção dominante;

•
intensidade normalizada;

•
idade do dado;

•
estado de qualidade;

•
período da janela;

•
símbolo e contrato.

As janelas devem ser configuráveis e, inicialmente, incluir:

•
janela curta;

•
janela do candle selecionado;

•
acumulado da sessão/dia;

•
opção de reset no início de candle ou sessão.

Não impor uma janela de reset arbitrária sem ler o timeframe efetivamente usado pelo projeto e sem deixar o parâmetro configurável.

import MetaTrader5 as mt5import pandas as pdimport time
# 1. Conecta ao MetaTrader 5if not mt5.initialize():
    print("Falha ao inicializar o MT5")
    mt5.shutdown()
symbol = "WDOU26"  # Substitua pelo contrato atual do minidólar ou WIN
mt5.symbol_select(symbol, True)

print(f"Monitorando fluxo real para {symbol}...")
# Variáveis para acumular o fluxo do candle atualsaldo_agressao_acumulado = 0
last_tick_time = 0
try:
    while True:
        # Pega os últimos 100 ticks para garantir que não perdeu nenhum
        ticks = mt5.copy_ticks_from(symbol, int(time.time()) - 5, 100, mt5.COPY_TICKS_ALL)
        
        if ticks is not None and len(ticks) > 0:
            df_ticks = pd.DataFrame(ticks)
            
            # Filtra apenas os ticks novos desde a última checagem
            df_ticks = df_ticks[df_ticks['time_msc'] > last_tick_time]
            
            if not df_ticks.empty:
                for index, row in df_ticks.iterrows():
                    flags = row['flags']
                    volume = row['volume']
                    
                    # Verifica a direção da agressão usando as flags binárias do MT5
                    is_buy = flags & mt5.TICK_FLAG_BUY
                    is_sell = flags & mt5.TICK_FLAG_SELL
                    
                    if is_buy:
                        saldo_agressao_acumulado += volume
                    elif is_sell:
                        saldo_agressao_acumulado -= volume
                
                # Atualiza o timestamp do último tick processado
                last_tick_time = df_ticks['time_msc'].max()
                
                # -------------------------------------------------------------
                # AQUI: Envie o 'saldo_agressao_acumulado' para o seu Dashboard
                # Exemplo visual: Se positivo -> Barra Verde | Se negativo -> Barra Vermelha
                # -------------------------------------------------------------
                print(f"Saldo de Agressão Atual: {saldo_agressao_acumulado} contratos")
                
        time.sleep(0.05)  # Checa a cada 50ms para precisão de alta frequência
except KeyboardInterrupt:
    print("Monitoramento encerrado.")
    mt5.shutdown()

### 1. Script em Python Separado: Captura e Processamento do Fluxo

Este script roda de forma independente em segundo plano. Ele captura os ticks brutos do WDO/WIN, identifica o lado agressor através das *flags* do MT5 (`TICK_FLAG_BUY` e `TICK_FLAG_SELL`) e calcula o **Saldo de Agressão (Delta)** a cada candle ou janela móvel de tempo.

Crie o arquivo `servico_fluxo_real.py`:

```python
import MetaTrader5 as mt5
import pandas as pd
import time
import json

def inicializar_mt5(symbol):
    if not mt5.initialize():
        print("Erro ao inicializar MetaTrader5")
        return False
    mt5.symbol_select(symbol, True)
    return True

def classificar_pressao_fluxo(saldo_agressao, threshold_forte=500, threshold_fraco=100):
    """
    Mapeia o saldo numérico em cores e estados para o Dashboard e o Robô.
    """
    if saldo_agressao >= threshold_forte:
        return {"cor": "#00FF00", "estado": "COMPRA_FORTE", "score": 1.0}  # Verde Claro / Neon
    elif saldo_agressao >= threshold_fraco:
        return {"cor": "#228B22", "estado": "COMPRA_MODERADA", "score": 0.5} # Verde Escuro
    elif saldo_agressao <= -threshold_forte:
        return {"cor": "#FF0000", "estado": "VENDA_FORTE", "score": -1.0}  # Vermelho Vivo
    elif saldo_agressao <= -threshold_fraco:
        return {"cor": "#8B0000", "estado": "VENDA_MODERADA", "score": -0.5} # Vermelho Escuro
    else:
        return {"cor": "#808080", "estado": "NEUTRO", "score": 0.0}       # Cinza

def monitorar_fluxo(symbol="WDO$", janela_segundos=300):
    """
    Calcula o saldo de agressão nos últimos N segundos (ex: 300s = 5 min).
    """
    if not inicializar_mt5(symbol):
        return

    print(f"🚀 Monitor de Fluxo Real ativado para {symbol}")
    last_processed_msc = 0

    try:
        while True:
            agora_msc = int(time.time() * 1000)
            inicio_janela_msc = agora_msc - (janela_segundos * 1000)

            # Solicita os ticks da janela móvel
            ticks = mt5.copy_ticks_range(symbol, inicio_janela_msc, agora_msc, mt5.COPY_TICKS_ALL)

            if ticks is not None and len(ticks) > 0:
                df = pd.DataFrame(ticks)

                # Filtro de Agressão via Bitwise Flags do MT5
                # TICK_FLAG_BUY = Agressão de Compra | TICK_FLAG_SELL = Agressão de Venda
                df_buys = df[(df['flags'] & mt5.TICK_FLAG_BUY) != 0]
                df_sells = df[(df['flags'] & mt5.TICK_FLAG_SELL) != 0]

                vol_compra = df_buys['volume'].sum() if not df_buys.empty else 0
                vol_venda = df_sells['volume'].sum() if not df_sells.empty else 0

                saldo_agressao = vol_compra - vol_venda
                classificacao = classificar_pressao_fluxo(saldo_agressao)

                payload_fluxo = {
                    "timestamp": time.strftime("%H:%M:%S"),
                    "symbol": symbol,
                    "vol_compra": int(vol_compra),
                    "vol_venda": int(vol_venda),
                    "saldo_agressao": int(saldo_agressao),
                    "cor": classificacao["cor"],
                    "estado": classificacao["estado"],
                    "score_fluxo": classificacao["score"]
                }

                # 1. Salva estado atual em disco para leitura instantânea por outros módulos/robô
                with open("logs/fluxo_real_state.json", "w") as f:
                    json.dump(payload_fluxo, f, indent=2)

                print(f"[{payload_fluxo['timestamp']}] Saldo: {saldo_agressao:+d} | Estado: {payload_fluxo['estado']}")

            time.sleep(0.1) # Atualização a cada 100ms (Baixa Latência)

    except KeyboardInterrupt:
        print("Encerrando monitor de fluxo.")
        mt5.shutdown()

if __name__ == "__main__":
    monitorar_fluxo("WDO$", janela_segundos=300)

```

### 2. Como Integrar ao Dashboard em Flask (Porta 5001)

No front-end do seu dashboard, você pode adicionar um **Card/Indicador Visual de Fluxo Real** que altera dinamicamente sua cor de fundo e exibe o saldo de agressão.

#### A. Rota no Flask (`app.py` do Dashboard)

Adicione um *endpoint* simples no Flask para entregar o estado atual do fluxo:

```python
from flask import Flask, jsonify
import json
import os

@app.route('/api/fluxo_real')
def get_fluxo_real():
    path_fluxo = "logs/fluxo_real_state.json"
    if os.path.exists(path_fluxo):
        with open(path_fluxo, "r") as f:
            data = json.load(f)
        return jsonify(data)
    return jsonify({"estado": "INDISPONIVEL", "cor": "#808080", "saldo_agressao": 0})

```

#### B. Componente HTML/JavaScript (No Template do Dashboard)

Adicione o painel visual com atualização automática via JS:

```html
<!-- Painel Visual do Fluxo Real -->
<div id="card-fluxo" style="padding: 15px; border-radius: 8px; color: white; background-color: #808080; text-align: center; font-family: sans-serif;">
    <h3>FLUXO REAL (AGRESSÃO)</h3>
    <h1 id="texto-saldo">0</h1>
    <span id="texto-estado">CARREGANDO...</span>
</div>

<script>
function atualizarFluxo() {
    fetch('/api/fluxo_real')
        .then(response => response.json())
        .then(data => {
            const card = document.getElementById('card-fluxo');
            const textoSaldo = document.getElementById('texto-saldo');
            const textoEstado = document.getElementById('texto-estado');

            card.style.backgroundColor = data.cor;
            textoSaldo.innerText = (data.saldo_agressao > 0 ? "+" : "") + data.saldo_agressao + " ctrs";
            textoEstado.innerText = data.estado;
        })
        .catch(err => console.error("Erro ao carregar fluxo:", err));
}

// Atualiza a cada 500ms na tela
setInterval(atualizarFluxo, 500);
</script>

```

### 3. Como usar o Fluxo para Ajustar Entradas e Saídas no Robô

No seu robô principal, você pode consultar o arquivo `logs/fluxo_real_state.json` antes de tomar uma decisão de compra/venda ou para ajustar ordens em aberto:

```python
import json

def obter_score_fluxo():
    try:
        with open("logs/fluxo_real_state.json", "r") as f:
            data = json.load(f)
            return data.get("score_fluxo", 0.0) # Retorna entre -1.0 e +1.0
    except:
        return 0.0 # Se falhar a leitura, assume neutro

# --- EXEMPLO DE USO NOS GATES / ENTRADAS ---
score_fluxo = obter_score_fluxo()

# Filtro de Entrada: Só compra se o fluxo estiver ao menos moderadamente comprador
if sinal_compra_modelo and score_fluxo >= 0.5:
    executar_compra()
elif sinal_compra_modelo and score_fluxo < 0.5:
    print("⛔ COMPRA BLOQUEADA: Fluxo Real não confirma a agressão de compra!")

# --- EXEMPLO DE USO PARA SAÍDAS (TRAILING STOP / EXIT) ---
# Se estamos comprados e o fluxo vira "VENDA_FORTE" (-1.0), encerra a posição antecipadamente
if posicao_atual == "LONG" and score_fluxo == -1.0:
    encerrar_posicao_a_mercado(motivo="Inversão de Fluxo Institucional")

```

### 💡 Resumo dos Benefícios

1. **Desacoplado:** Não pesa o *loop* principal de execução do robô.
2. **Visual Instintivo:** Transforma tabelas complexas do *Times & Trades* em uma barra de status simples (Verde = Institucional Comprando / Vermelho = Institucional Vendendo).


3. **Métrica Objetiva para o Robô:** Gera um valor numérico (`score_fluxo` de -1.0 a +1.0) que pode ser usado como trava de segurança ou filtro de entrada/saída.
